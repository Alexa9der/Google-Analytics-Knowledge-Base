# Scope and official sources

This report covers only Google Play Console Ratings, Reviews, developer replies, Reviews API,
ratings/reviews CSV delivery, history, display metadata, and private testing feedback. Canonical
claims remain in Facts; provenance remains in Evidence.

# Established facts and ratings

Google Play uses a 1–5 star scale. A user can maintain one updatable rating per app. The public
rating is weighted toward recent ratings, while lifetime average describes the period since first
launch. The exact weighting formula is not documented. UI performance provides period and rolling
lifetime averages, distributions, peer comparisons, date ranges, aggregation periods, breakdown
dimensions, and CSV download.

# Reviews and developer replies

A written review contains comment text; rating-only feedback does not. Reviews UI supplies filters,
sorting, search, translation, original text, display name, timestamp, optional environment metadata,
and reply/change history. A reply requires permission, is public, can be edited, and triggers user
notification under the documented interaction rules.

# API

Android Publisher v3 reviews provides get, list, and reply. It is production-only and excludes
rating-only submissions. List retrieval is restricted to reviews created or modified in the last
week, with token pagination. Translation can return translated and original text. The documented
identity field is authorName; no verified-person interpretation is made. Device and app metadata
are optional. Per-app GET and POST quotas are separately documented.

# CSV, dimensions, history, and freshness

Reviews is a detailed monthly report; ratings is an aggregated statistics export. Reviews CSV can
carry original review and reply timestamps/text. Ratings CSV carries daily and total averages over
supported dimensions. GCS files are posted after the documented three-to-seven-day lag. UI lifetime
ratings history, API one-week history, and monthly CSV availability are separate scopes.

# Public versus testing feedback and privacy

Open or closed testers can provide private feedback. It is not a public production review and does
not affect the public rating. Review authorName is exposed as display metadata, not established as
a pseudonym, legal identity, email, or stable user ID. No privacy-thresholding behavior is documented
for these reports.

# Uncertainties, coverage, and next phase

Unconfirmed topics include the exact recent-rating weighting formula, deleted-review retention,
rating/review edit propagation delay beyond the public hold, exhaustive UI filters, acquisition
channel as a rating dimension, country in the API resource, rating-only rows in Reviews CSV, direct
BigQuery export, and whether authorName is pseudonymous. The recommended next phase is Phase 1.6 —
Google Play Console Android Vitals Research; it has not been started.
